# Сборка, развёртывание и локальный запуск

## Требования
- Docker 24+ и Docker Compose v2. Сервер: 2 vCPU, 4 ГБ RAM, 10 ГБ диска (без Keycloak хватит и 2 ГБ RAM).
- Порт 80 (или любой другой через `HTTP_PORT`) и 8025 для веб-интерфейса почты (по желанию).

## Развёртывание на сервере
```bash
git clone <репозиторий> proof && cd proof
cp .env.example .env
#   PUBLIC_URL=http://<ip-или-домен>   — нужен для ссылок в письмах
#   JWT_SECRET=<длинная случайная строка>
#   HTTP_PORT=80
docker compose up -d --build
docker compose logs -f backend      # дождитесь строки «шаурматч_ API: …»
```
Проверка:
- `http://<сервер>/` — приложение;
- `http://<сервер>/api/docs` — Swagger;
- `http://<сервер>/api/health` — `{"status":"ok"}`;
- `http://<сервер>:8025` — входящие письма (Mailpit).

**HTTPS.** Поставьте перед контейнером `frontend` обратный прокси с сертификатом (Caddy, nginx + certbot) и укажите `PUBLIC_URL=https://…`. Cookie станут `Secure` автоматически.

**Вход через ФСП ID (Keycloak), по желанию:**
```bash
docker compose -f docker-compose.yml -f docker-compose.keycloak.yml up -d --build
```
Keycloak доступен на `:8180` (admin / `KEYCLOAK_ADMIN_PASSWORD`), демо-пользователь `fsp.demo` / `shaurma2026`. Если сервер не на localhost, задайте `KEYCLOAK_PUBLIC_URL=http://<сервер>:8180`.

**Реальная почта.** Задайте `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM` и `DEMO_MODE=false`: ссылка подтверждения перестанет показываться на экране.

**LLM.** `GIGACHAT_AUTH_KEY` или `YANDEX_API_KEY` + `YANDEX_FOLDER_ID` — по желанию.

## Управление данными
```bash
docker compose exec backend node dist/seed.js --reset   # пересоздать демо-данные
docker compose down -v                                   # удалить всё, включая БД
```
Отключить автонаполнение: `SEED_ON_START=false`.

## Локальный запуск без Docker (для разработки)
См. раздел «Локальная разработка» в [README](../README.md). Нужны Python 3.12+ и Node.js 22+ (Node используется движком для исполнения JS-вариантов).

## Пересчёт валидации метода
```bash
cd engine && pip install -r requirements.txt
python -m validation.simulate --n 2000 --seed 42
# результат: docs/validation/report.md, metrics.json, *.png
```

## Примечание для Windows
Если путь к проекту содержит кириллицу, `docker compose build` может упасть с ошибкой `x-docker-expose-session-sharedkey`. Запускайте `COMPOSE_BAKE=false docker compose up -d --build`.
